# Codebility

The Codebility web app: auth, the applicant pipeline with admin approval, and the public marketing site. Built with Next.js and Supabase.

Run it from the repo root with `pnpm codebility` after creating `apps/codebility/.env.local` with the variables listed in the `env` block of `.github/workflows/ci.yml`.

Before adding or moving files, read [`AGENTS.md`](../../AGENTS.md) for the folder structure and contribution rules.
